# 图片比例转换 + 去头工具

一个在自己电脑上运行的 Windows 小工具，用来处理角色设定图 / 三视图：

- **一键转 21:9**：左右补黑边（或接近背景色的边），人物不变形，原图像素一个都不改。
- **框选去头**：在图上拖框框住全身人物的头，从框的下边切掉，空出来的地方用背景补上。适合把全身三视图做成「只看服装」的参考图。
- **删掉某一格**：自动识别横排的分格（比如人脸三视图），点选要删的格子（三格时默认选中间那格），剩下的格子原样拼接后再转 21:9。
- **笔刷修补**：涂掉耳坠等零碎残留，用周围的颜色补上。
- **自己选位置保存**，PNG 无损格式，保留原图的分辨率信息和色彩配置。

全程本地计算，**不联网、不调用任何 API**。

## 下载

到右边的 [Releases（发行版）](../../releases) 页面下载 `image-ratio-dehead-tool-*.exe`，双击就能用，不需要安装 Python。

第一次打开时 Windows 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。这是因为 exe 没有购买数字签名。

## 使用步骤

窗口顶部会显示当前进行到第几步：

1. **拖入图片**：把图片拖进窗口（可以一次拖多张或拖整个文件夹），也可以点「+ 添加图片…」。
2. **选择处理方式**
   - 「只转 21:9」
   - 「框选头部 → 去头 + 转 21:9」：在图上按住左键拖出红框，框的下边（橙线）就是切口；可以框多个，也可以点「自动帮我框（可选）」让工具先帮你框，再自己检查。框好后点「✓ 开始去头」。
   - 「删掉某一格 → 转 21:9」：工具自动找出分格，点一下要删的格子（变红），分界线可以拖动微调、格数可以手动改，然后点「✓ 删除选中的格 + 转 21:9」。原图如果已经带黑边，会先去掉旧黑边再重新补。
3. **检查 / 修补**：滚轮放大，按住右键拖动画面，按住空格对比原图；有残留就勾选笔刷涂掉，再点「修补涂抹处」。
4. **保存**：点「保存…」，自己选位置和文件名。

目标比例除了 21:9，也可以选 16:9、2.35:1 等，或者自己填。

## 限制

- 盖在衣服上的长发（比如侧面人物背后的长发）会保留，因为头发下面的衣服看不见，补不出来。脖子两边、背景前面的短发会去掉。
- 耳坠垂在衣领上的那一段需要用笔刷补一下。
- 「自动帮我框」依靠人脸识别，脸被遮住或画风过于卡通时可能认不出来，手动框即可。

## 从源码运行 / 打包

需要 Windows + Python 3.10 以上。

```bash
pip install -r requirements.txt
python app/crop_tool.py
```

打包成 exe：双击 `重新打包成exe.bat`（或运行 `python app/build_exe.py`），生成的 exe 在 `dist/` 文件夹。

文件说明：

| 文件 | 作用 |
|---|---|
| `app/crop_tool.py` | 窗口界面和操作流程 |
| `app/core.py` | 图像算法：比例转换、人脸识别、去头填补、笔刷修补 |
| `app/build_exe.py` | 打包成单个 exe |
| `app/face_detection_yunet_2023mar.onnx` | 人脸识别模型 |
